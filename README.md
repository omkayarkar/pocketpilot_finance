# PocketPilot — Your Money, Before You Spend It

**PocketPilot** is an interactive personal finance simulator built for students and young adults. Start with ₹10,000, simulate expenses, manage savings goals, track recurring payments, and understand how spending decisions affect your financial future.

## ✨ Features

- **Financial Overview:** Track your balance, spending, savings, and projected finances.
- **Spend Simulator:** Preview expenses before committing to a purchase.
- **Transaction Tracking:** Review your financial activity.
- **Savings Goals:** Track progress toward savings targets.
- **Recurring Payments:** Monitor subscriptions and upcoming commitments.
- **Financial Health:** Understand budget sustainability and savings feasibility.
- **Local Persistence:** Save your data in your browser.
- **Responsive Design:** Use the application on desktop and mobile screens.

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React
- Browser Local Storage

## 🚀 Run Locally

### Prerequisites

Install [Node.js](https://nodejs.org/).

### Installation

Clone the repository:

```bash
git clone https://github.com/omkayarkar/pocketpilot_finance.git
```

Enter the project directory:

```bash
cd pocketpilot_finance
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in your terminal.

## 📦 Production Build

```bash
npm run build
```

## 💡 How It Works

PocketPilot starts with a sample budget of ₹10,000 over 30 days. Explore spending scenarios, evaluate upcoming commitments, work toward savings goals, and observe how your decisions affect your projected finances.

The initial transactions and goals are sample data for simulation.

## 🔒 Privacy

Application data is stored in your browser's local storage. It is not automatically synchronized across devices.
